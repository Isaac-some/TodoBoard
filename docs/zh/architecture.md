# 架构与路线

工作链路是：**工作资料留存 → OV 归档与记忆 → Todo 候选 → 人工接纳 → 分发 Agent → 结果回传 → 人工完成 → 经验留存**。

唯一产品界面是 Mac TodoBoard。后台负责采集、资料原文、队列、背景检索、执行回执与结果跟踪。Agent 继续使用自己的对话、审批、工具和 Skills。Board 不是另一套执行 harness。

[打开 Archify 交互架构图](../architecture.html) · [打开工作路线图](../workflow.html)

`tasks.json` 是卡片唯一数据源，Swift 与 Python 共用 `tasks.lock`。保存前重读、字段级合并及原子替换避免旧界面覆盖后台新增的卡片或结果。`runtime.sqlite` 仅保存处理队列、游标、事件和投递台账。

资料原文位于后台 `materials/`，知识库默认是官方未修改的 OV 0.5.2.1。卡片只携带引用和摘要。知识库离线时本地资料保留并重试，分发可以回退到已保留的原文，并明确记录缺失背景。

原始事件时间与卡片添加时间分别保存。来源和行动项确定候选身份，垃圾桶保留身份用于去重。执行结果更新 `execution`，完成状态由用户操作 Board 写入。

本版范围是 Mac Board、独立后台、三类来源、Codex 适配、知识库协议与开发文档。日程助手界面、晨晚报、云端交接不在本版。未来扩展沿现有接口增加 Agent 和知识库，不要求重写 Board。
