# 验证记录

验证范围按实际执行更新；未验证的 Agent 不列为支持。详细可重复检查在 `Tests/`、`tests/`，部署版本锁在 `config/versions.json`。

- Swift 测试：卡片状态、日期、外部写入、损坏恢复、Agent 配置、工作区书签、队列去重与投递恢复。
- Python 测试：空配置、并发写入、原文留存、OV 离线、归档门槛、证据约束、丢弃去重、结果与完成分离、CLI 持久投递与 Hook 作用域。
- 官方 OV：使用独立测试目录、未修改的 0.5.2.1 包验证；真实服务检查结果在发布前补充。
- Codex：CLI 与 GUI 使用同一事件协议，真实投递与回传的检查结果在发布前补充。
- 飞书：采集接口与权限文档按官方 CLI 核对；真实账号权限不能保证其他开发者拥有相同资源可读性。

单元测试中的 FakeOV 与合成会议数据是接口行为验证，不代表真实模型的检索质量。GUI 自动化与原生审批的边界在 Codex 指南中说明。
