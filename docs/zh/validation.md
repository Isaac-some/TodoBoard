## 智能体名单与头像选择（2026-11-02）

- 新安装和空名单不自动生成演示角色；持久化名单按原配置恢复。
- 添加智能体时，在同一窗口填写名称、选择内置头像；默认优先推荐尚未使用的头像，允许复用。
- 名称支持中文和 Emoji 粘贴、剪切和撤销；空名称不能提交，重名在窗口内提示，Escape 取消且不创建角色。
- 所选头像写入角色配置并经过启动恢复、配置完成检查验证；配置交接不能悄悄替换用户所选头像。
- Swift 共 43 项测试通过。另在独立测试数据目录实测了四个头像按钮、取消、重名提示、创建和重启持久化；该界面测试未向 Codex 投递真实请求。
