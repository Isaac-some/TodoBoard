# Third-party components

TodoBoard's Swift application, Python runtime and documentation are MIT. The original author's application and read-only meeting collector were extracted into a new repository with no personal history or runtime data. The included avatars are synthetic letter images generated by `scripts/create-avatars.swift`.

OpenViking **0.5.2.1** is an optional, unmodified external service published by [Volcano Engine](https://github.com/volcengine/OpenViking). Its server and source retain **AGPL-3.0**; TodoBoard does not relicense, embed, or ship that server in its Mac app. Install from the official release. No patches from the author's old installation are included. Official OpenViking agent plugins have their own upstream notices and are installed separately.

Feishu access uses the external official [`@larksuite/cli` 1.0.98](https://github.com/larksuite/cli), **MIT**. No CLI binary, account, token or personalized Skills are redistributed.

Developer diagrams use [Archify](https://github.com/tt-a1i/archify), **MIT**. Generated HTML retains its bundled notices. The documentation uses **VitePress 1.6.4**, **MIT**, and its dependency notices. Exact npm dependencies and integrity values are in `package-lock.json`.

Codex CLI and the Codex desktop app are installed by the developer under their respective upstream terms. Neither is bundled. Other agents are connected through a command adapter and retain their own terms.
